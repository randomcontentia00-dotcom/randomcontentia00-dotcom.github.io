Política de privacidad

Última actualización: 18 de noviembre de 2026

Qué es esta aplicación

Gestor Redes IA es una herramienta privada que usa el propietario del proyecto ContentIA Random para administrar sus propias cuentas de YouTube, Instagram y TikTok.

Qué datos usa

  • Datos del canal o cuenta autorizada: nombre, identificador, número de seguidores y vídeos.
  • Datos de los vídeos publicados: títulos, descripciones, etiquetas y estadísticas de rendimiento.
  • Tokens de acceso concedidos mediante OAuth para actuar sobre esas cuentas.

Para qué los usa

Únicamente para subir y editar vídeos, consultar estadísticas y generar informes del propio canal. Los datos no se venden, no se ceden a terceros y no se usan para publicidad.

Datos de Google y YouTube

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Al usar funciones de YouTube se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Almacenamiento y seguridad

Los tokens se guardan cifrados en el entorno privado del propietario y nunca se publican.

Cómo revocar el acceso

Puedes retirar el permiso en cualquier momento desde myaccount.google.com/permissions o desde la configuración de Instagram y TikTok. Al revocarlo se dejan de usar los datos.
